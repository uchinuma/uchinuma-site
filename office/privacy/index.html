内沼事務所 / uchinuma-office プライバシーポリシー

最終更新日：2026年9月30日

「内沼事務所 / uchinuma-office」（以下「本アプリ」）は、内沼晋太郎本人が自身の業務を支援するために開発・利用している個人用アプリケーションです。

本アプリは現在、一般ユーザー向けには提供しておらず、内沼晋太郎本人のみが利用しています。

1. Googleユーザーデータへのアクセス

本アプリは、本人の許可に基づき、Google APIを通じて必要な範囲のGoogleユーザーデータにアクセスします。

現在利用しているデータは、以下のとおりです。

Google Calendar

  • カレンダー一覧
  • 予定のタイトル
  • 開始日時・終了日時
  • 終日予定かどうか
  • Google Calendar上の予定へのリンク

Gmail

  • メールスレッドおよびメッセージのID
  • 件名
  • 送信者
  • 宛先（To / Cc）
  • 日時
  • Gmailのシステムラベル

現在のGmail連携では、メール本文、添付ファイル、本文のスニペットを取得・保存しません。

2. 利用目的

Googleから取得したデータは、以下の目的にのみ利用します。

  • 本人の当日の予定を把握する
  • 確認や対応が必要と思われるメールを整理する
  • 本人の業務上のタスクやプロジェクトを管理する
  • 本人が見落としを防ぎ、業務を進めるための支援を行う

取得したGoogleユーザーデータを、広告、マーケティング、ユーザーのプロファイリング、第三者への販売のために利用することはありません。

3. データの保存

本アプリが保存する業務データは、原則として内沼晋太郎が管理するMac上に保存します。

OAuthのクライアント情報およびリフレッシュトークンなどの認証情報は、macOS Keychainに保存します。

Googleユーザーデータや認証情報を、ソースコードの公開・保管先であるGitリポジトリに保存することはありません。

4. 第三者への共有

現在、本アプリがGoogle APIから取得したGoogleユーザーデータを、第三者へ販売または提供することはありません。

現在のGmailメタデータ取得処理では、取得したGoogleユーザーデータを外部のAIサービスへ送信していません。

今後、外部AIサービスを利用してメール本文の分類、要約、返信案作成などを行う機能を追加する場合は、送信するデータの範囲、利用目的、保存方針を本ポリシーに明記し、必要なGoogle API権限について本人が改めて承認します。

5. データの削除

本アプリに保存されたGoogle由来のデータは、本人の判断によりローカル環境から削除できます。

また、Googleアカウントの設定から本アプリへのアクセス権を取り消すことができます。アクセス権を取り消した後、本アプリは新たにGoogleユーザーデータを取得できません。

6. Google API Services User Data Policy

本アプリによるGoogle APIから取得した情報の利用は、Google API Services User Data Policyに従い、Restricted Scopeに関するLimited Use要件を含む適用可能な要件に準拠して行います。

Googleユーザーデータは、本アプリの明示された機能を提供するために必要な範囲に限って利用します。

7. セキュリティ

本アプリは、Googleユーザーデータへのアクセスを必要最小限の権限に限定し、Google CalendarとGmailの認証情報を分離して管理します。

ローカルに保存するデータについても、OSのアクセス制御やディスク暗号化などを利用して、不必要なアクセスを防ぐよう管理します。

8. 本ポリシーの変更

本アプリの機能やGoogleユーザーデータの利用方法を変更した場合は、本ポリシーを更新します。

特に、取得するGoogle APIの権限、保存するデータ、第三者サービスへのデータ送信方法に変更がある場合は、その内容を本ポリシーに反映します。
